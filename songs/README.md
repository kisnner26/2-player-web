# songs/

Aquí van tus propios archivos de audio (mp3/ogg/m4a) para los juegos
rítmicos (`26-ritmo`, `57-baile-dos`). El proyecto sigue siendo 100%
offline: nada de esta carpeta se sube a ningún sitio, solo se lee en local.

**Importante:** solo pon aquí música que ya tengas de forma legítima (CDs
propios, compras digitales, exportaciones de un servicio al que estés
suscrito, etc.). No se puede descargar música con derechos de autor desde
"sitios gratuitos" de internet — eso no es legal sin importar cómo se
presente el sitio, así que esa parte no la automatizo.

Cuando la biblioteca de música esté conectada (en curso), la app detectará
los archivos de esta carpeta automáticamente y te dejará ponerles BPM con
un botón de tap-tempo antes de jugar.
